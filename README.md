# Yes-bank-project
Analyzed 185 months of Yes Bank stock prices (2005–2020) using Python, Pandas, Matplotlib, Seaborn and SciPy. Ran EDA, candlestick and moving-average charts, and hypothesis tests showing volatility rose after 2018. Built Linear Regression and Random Forest models to predict next-month closing price (R² 0.90) and compared them with a naive baseline.
